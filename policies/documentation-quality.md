# Documentation quality

We use CHANGELOG formatting based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and versioning adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Try to keep up-to-date with CHANGELOG updates, which can be more informal than official Release Notes, so that the community can keep up with improved functionality or bugfixes.

We use [Diátaxis](https://diataxis.fr/) as an inspiration to adhere to when documenting our code and processes. This approach allows us to have common documentation goals, including how-tos and tutorials.
